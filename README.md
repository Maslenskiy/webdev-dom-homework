# Комментарии — учебный проект для портфолио

## Деплой проекта: https://webdev-comments.netlify.app

Одностраничное приложение для работы с комментариями: загрузка списка, добавление, лайки, ответы с цитированием и базовая авторизация. Проект выполнен в учебных целях, но оформлен как готовый кейс для портфолио.

## Описание проекта

Интерфейс позволяет просматривать список комментариев, ставить/снимать лайки, добавлять новые комментарии и отвечать с цитированием исходного сообщения. Реализованы состояния загрузки, обработка ошибок и формы входа/регистрации.

## Основные возможности

- Загрузка и рендер списка комментариев
- Добавление комментария с валидацией полей
- Ответ с цитированием (pre-fill текста)
- Лайки с визуальной индикацией и анимацией
- Состояния загрузки и ошибок
- Авторизация и регистрация (экраны и обработчики)

## Использованные технологии

- HTML5, семантическая разметка
- CSS3 (Flexbox, адаптивные контейнеры, градиенты)
- JavaScript (ES-модули)
- ESLint + Prettier (настройки в `eslint.config.mjs`, `package.json`)

## Структура проекта

```
index.html           — точка входа
index.js             — инициализация и загрузка комментариев
styles.css           — стили интерфейса
modules/
  authorization.js   — логика авторизации
  clearingHtml.js    — экранирование/очистка HTML
  comments.js        — хранилище/модель комментариев
  delay.js           — утилита задержки
  formattedDate.js   — форматирование дат
  getComments.js     — получение комментариев
  initListeners.js   — навешивание обработчиков
  loadingMessage.js  — сообщения о загрузке
  postComments.js    — отправка комментариев
  renderComments.js  — шаблоны и рендер списка
  renderLogin.js     — рендер экрана входа
  renderReg.js       — рендер экрана регистрации
```

## Установка и запуск

Способ 1 (простой, без сервера):

1. Склонировать репозиторий
2. Открыть `index.html` в браузере (двойной клик или через Live Server в VS Code)

Способ 2 (c локальным статическим сервером):

1. Склонировать репозиторий
2. Установить зависимости для линтинга/форматирования (необязательно для запуска):
   ```bash
   npm install
   ```
3. Запустить любой статический сервер (напр. `npx serve` или расширение Live Server) и открыть корень проекта
